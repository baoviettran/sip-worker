# sip-worker

Signaling-only SIP stack (RFC 3261) browser entry point. This package is owned
by the sip-worker project and exposes the browser `UserAgent` and common API.

`sip-worker` does **not** add WebRTC or make any production-browser claim. See
the migration guide for the 0.2.0 to 0.3.0 mapping:
<https://github.com/baoviettran/sip-worker/blob/main/docs/migrations/0.2-to-0.3.md>
