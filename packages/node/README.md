# @sip-worker/node

Signaling-only SIP stack (RFC 3261) node transport and reliability entry point.
This package is owned by the sip-worker project.

`@sip-worker/node` does **not** add WebRTC or make any production-readiness
claim. See the migration guides for the 0.2.0 to 0.3.0 mapping:
<https://github.com/baoviettran/sip-worker/blob/main/docs/migrations/0.2-to-0.3.md>,
the [0.3.0 to 0.5.0 step](../docs/migrations/0.3-to-0.5.md), which moves
the media controller/error contract into `@sip-worker/core`, and the
[0.5.0 to 0.7.0 step](../docs/migrations/0.5-to-0.7.md).
