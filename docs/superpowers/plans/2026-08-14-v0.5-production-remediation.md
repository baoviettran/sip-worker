# v0.5 Production Remediation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Correct every finding from the 2026-08-14 production review while preserving the approved v0.5 browser-media architecture, public behavior, security boundaries, and verification depth.

**Architecture:** Keep core responsible for SIP and bridge correlation and browser responsible for concrete media resources. Normalize configuration once at browser composition, bound browser operations inside the media manager, retain the controller's longer fallback deadline, and make every terminal path invalidate late work without historical per-call storage.

**Tech Stack:** TypeScript 5.5+, Vitest 2, WebRTC browser APIs, Playwright 1.62, API Extractor, tsup, npm workspaces, GitHub Actions, coturn.
